# RGB Value Analysis 术语表

| 术语 | 白话解释 |
| --- | --- |
| RGB | 建立在 Bitcoin 交易图之上的客户端验证资产与合约协议。 |
| 客户端验证 | 相关参与者在本地验证与自己有关的状态，不要求所有节点保存全部资料。 |
| UTXO | 一份尚未花费、可以被花费的 Bitcoin 交易输出。 |
| 一次性封印 | 绑定在可花费输出上的一次性权利封条，花费后旧封印失效。 |
| Consignment | 发送方交给接收方、用于验证 RGB 状态转移的资料包。 |
| Mint | 创建资产合约规则与初始状态的发行过程。 |
| Lightning | 通过支付通道实现快速、低成本价值转移的 Bitcoin 二层网络。 |
| RGB-LSP | 帮用户获得 RGB/Lightning 通道与流动性服务的一类服务提供者。 |
| DEX | 组织资产报价与交换的交易应用；非托管与否要看具体实现。 |
| LP | 提供资产库存、报价或通道资金，以换取费用或承担相应风险的流动性提供者。 |
| BTCFi | 围绕 BTC、RGB 资产和 Bitcoin 结算建立的金融活动与基础设施。 |

术语表只提供入门解释；发布文章时仍应链接对应的一手协议或产品资料。
