# 第 06 篇配图

本目录为《一次性封印到底封住了什么？》的四张配图，统一沿用项目封面的深森林绿、古金线稿、金色粒子和编辑感留白。

- `01-主视觉-一次性封印.png`：一项带有唯一封印的数字权利，以 Bitcoin 交易作为安全锚。
- `02-问题图-复制与一次性封印.png`：普通可复制文件与只能关闭一次的数字封印对照。
- `03-流程图-一次性封印的唯一性路径.svg`：定义封印、花费旧 UTXO、关闭旧封印、创建新封印、验证唯一性。
- `04-边界图-封印与责任.png`：封印、Bitcoin、RGB 状态资料、发行方信用和钱包资料的责任边界。
