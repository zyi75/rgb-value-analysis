# 《RGB Value Analysis》

## 重新理解 Bitcoin 应用层

> 从协议、基础设施、流动性到应用，系统理解 RGB 生态如何构建 Bitcoin 原生金融网络。

这不是一本通用 Crypto 项目分析书，而是一本只回答一个问题的中文开源书籍：

> **RGB 如何一步一步把 Bitcoin 从“价值储存网络”变成“价值流通网络”？**

全书按 RGB 的成长路线展开：

1. 为什么 Bitcoin 需要 RGB？
2. RGB 是如何工作的？
3. RGB 如何拥有 USDT？
4. RGB 如何形成流动性？
5. RGB 如何形成 BTCFi？
6. RGB 如何走向全球支付？

完整写作总纲：[book/00-开源书籍总纲-v2.0.md](book/00-开源书籍总纲-v2.0.md)
